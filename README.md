# food-ordering-system-sample

## Admin login

Import `database/schema.sql` into MySQL to create the database and demo admin account.
Then open `http://localhost/food-ordering-sample/admin/login.php` and sign in with:

- Email: `admin@foodie.local`
- Password: `FoodieAdmin@2026!`

The schema only creates this account if the email does not already exist. Change its
password before deploying the application publicly.
